# 코딩 규칙

## 최소주의 원칙
- 요청하지 않은 기능이나 추상화 구현 금지
- 200줄을 50줄로 줄일 수 있다면 줄인다
- 요청된 것만 구현한다

## 외과적 수정
- 기존 스타일을 그대로 유지한다
- 필요한 줄만 수정한다
- 인접 코드를 "개선"하거나 포맷 변경 금지

## 단일 책임
- 파일 하나 = 명확한 기능 하나
- 함수는 단일 목적만 수행

## 도구 vs 직접 코드
- 간단한 로직 변경: 직접 수정
- API 호출 또는 데이터 처리: 스크립트 기반 접근 우선

## 컴팩션 보존
컴팩션 시: 수정된 파일 전체 목록과 테스트 명령어 반드시 보존
